# Музей Ламановой: 5 концепций главной страницы

Открыть: `index.html`. Шрифты подгружаются с Google Fonts, нужен интернет.

## Как выложить на GitHub Pages
1. На github.com: New repository, имя например `lamanova-concepts`, Public.
2. Add file → Upload files: перетащить всё содержимое этой папки (не саму папку), Commit.
3. Settings → Pages → Source: Deploy from a branch, Branch: main, / (root), Save.
4. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/lamanova-concepts/`.
